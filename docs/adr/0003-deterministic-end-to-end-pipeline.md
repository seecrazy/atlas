# ADR 0003：端到端 Pipeline 先使用确定性 Worker

## 状态

已采纳

## 背景

Router、上下文包、影响链和汇聚器已经存在。直接接入 LLM Worker 可以快速产生自然语言结论，但会引入不可复现、幻觉证据、成本和权限边界模糊的问题。

## 决策

`atlas run` 先串联确定性结构 Worker。Worker 只根据 SQLite 索引和上下文包生成 claim 与 evidence，不读取函数体，不生成代码。

## 理由

1. Pipeline schema 稳定。
2. 每条 finding 都可追溯到索引证据。
3. 便于建立端到端冻结验证集。
4. 后续 LLM Worker 可以作为替换件接入，而不是改变权限模型。
5. 成本和延迟可预测。

## 后果

### 正面

- 可重复执行。
- 无模型成本。
- 证据边界明确。

### 负面

- 结论粒度受索引质量限制。
- 不能解释业务语义。

## 重新评估条件

1. 结构索引覆盖稳定。
2. Router accuracy 达到项目要求。
3. Worker 输出通过冻结验证集评估。
